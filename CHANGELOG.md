## [3.6.5+97] - 2026-07-16

### Меню и карточки блюд
- Выбор гарнира через нижний шит при каждом добавлении: «+» на карточке (меню, поиск, рекомендации) или «Добавить» на странице блюда открывает список гарниров с ценами «+N сом», бейджем «Обязательно» и кнопкой «В корзину» с ценой порции.
- Гарнир связан с блюдом одной позицией корзины: количество гарнира всегда равно количеству блюда, удаление блюда убирает его гарнир, одно блюдо с разными гарнирами — отдельные позиции. Позиции с одинаковым гарниром объединяются.
- В корзине гарнир показан строкой «+ Гарнир · цена» под блюдом, цена позиции — блюдо + гарнир.
- Фото блюд без обрезки и внутренних отступов: в карточках меню впритык к краям, на странице блюда — на всю ширину.
- Непрерывная лента меню строится лениво (построчно) — плавный скролл больших категорий.
- Исправлено падение заглушки при отсутствии фото блюда.

### История заказов
- Единый дизайн истории доставки и самовывоза: номер, статус, дата, разбивка стоимости.
- Фильтр по датам: «Все / Сегодня / 7 дней / 30 дней / Период» с выбором произвольного диапазона.

### Бонусы
- QR-код временно скрыт за заглушкой «Скоро появится» (функция готовится к запуску).

### Производительность
- Тяжёлые изображения переведены в WebP (−1,5 МБ), убраны лишние перестройки экранов курьера.

## [3.6.4+96] - 2026-07-03

### Меню и карточки блюд

### Корзина
- Блок «Так же заказывают» под корзиной.
- Компактный селектор столовых приборов.
- Устранены переполнения (overflow) в карточках корзины и меню при длинных названиях.

## [3.6.1+93] - 2026-05-29

### Курьерское приложение — фоновая геолокация:
- Добавлен Android Foreground Service (`flutter_foreground_task`): пока курьер на смене, система не убивает процесс и SignalR-сокет остаётся живым даже при заблокированном экране.
- iOS: добавлен `UIBackgroundModes: location` — приложение продолжает получать обновления геолокации в фоне.
- Foreground Service запускается автоматически при выходе на смену и останавливается при выходе со смены; при перезапуске приложения состояние восстанавливается.
- Добавлен обработчик `ShiftStatus` в SignalR-хабе курьера (сервер присылал событие, клиент игнорировал).
- Уменьшена задержка переподключения хаба с 60 с до 5 с — курьер пропадал с карты до минуты после разрыва.

### Меню — исправление отображения фото:
- Фото блюд в сетке больше не растягиваются: виджет теперь использует thumbnail (`imageUrlForList`) вместо полноразмерного изображения.
- `AspectRatio` контейнера изменён с 1.05 до 1.0 под квадратные (512×512) thumbnails.
- Убран `memCacheHeight` — высота кэша теперь масштабируется пропорционально реальным размерам изображения.
- Исправление распространяется на сетку меню, поиск и раздел популярных блюд.

### Меню — навигация по категориям:
- В конце списка блюд появляется карточка «Следующий раздел: [название]» — пользователь видит что впереди и может тапнуть.
- При долистывании до конца категория переключается автоматически (плавная прокрутка таба + загрузка блюд).
- При смене категории скролл сбрасывается в начало списка.

### Исправления:
- Исправлен краш APK при запуске: `CourierForegroundService.start()` вызывался до получения разрешений — теперь запускается в странице после подтверждения прав.
- Исправлен вылет из приложения при любой сетевой ошибке в `getUser()`: logout теперь выполняется только при 401/403, при прочих ошибках показывается snackbar.
- Разрешения геолокации и уведомлений запрашиваются один раз при открытии экрана курьера, а не каждые 2 секунды из таймера (что ранее блокировало навигацию).
- Исправлен обработчик `RequestShiftConfirm`: при переподключении SignalR сервер запрашивал подтверждение статуса смены, клиент не отвечал.

## [3.6.0+92] - 2026-05-24

### Курьерское приложение — редизайн и реал-тайм:
- Полный редизайн главной страницы курьера: убран AppBar, добавлен заголовок с аватаром (инициалы), карточка смены с анимированной зелёной точкой.
- Дравер перенесён на правую сторону; переключатель смены убран из дравера.
- Добавлены шиммер-скелетоны при загрузке страницы курьера, списка заказов и истории.
- Редизайн карточки истории заказов: белая карточка с тенью, дата как серый чип.
- Заменён REST-поллинг (30 с) на реал-тайм через SignalR Hub: события `MyOrders`, `OrderAssigned`, `OrderDelivered`.
- При входе/выходе на смену хаб получает команду `SetOnShift`; после переподключения состояние смены и список заказов восстанавливаются автоматически.

### Исправления:
- Исправлена ошибка 502 Bad Gateway при переподключении SignalR: добавлены `skipNegotiation: true` и принудительный транспорт WebSockets с интервалами реконнекта [2000, 5000, 10000] мс.
- Исправлено отображение сырого JSON в снекбаре при ошибке оформления заказа: сервер возвращал объект ошибки в поле `message` при HTTP 200 — теперь извлекается читаемое сообщение.
- Исправлена задержка снекбаров: `hideCurrentSnackBar()` вызывается перед каждым `showSnackBar`.

### Рефакторинг:
- Удалены мёртвые виджеты (`call_button_widget`, `end_shift_section`).
- Исправлена опечатка `DateBotton` → `DateButton`.
- Выделена константа `CurierConstants.statusCooked` вместо строкового литерала.
- Добавлен `AppColors.backgroundGrey` (`Color(0xFFF2F2F7)`).

## [3.5.9+91] - 2026-05-21

### Исправления:
- Исправлен механизм обновления токенов: refresh token теперь работает корректно для всех datasource-ов (ранее sl<Dio>() не имел обработки 401).
- Устранён дедлок при обновлении токена: запрос на /refresh-token теперь идёт через отдельный Dio без QueuedInterceptorsWrapper.
- Исправлено затирание номера телефона после рефреша (phone: '' → null).
- Устранён двойной рефреш при параллельных 401-ошибках.
- Исправлено сохранение нового refresh token после ротации (ранее сохранялся старый).
- При невалидном refresh token (401) приложение теперь автоматически разлогинивает пользователя и перенаправляет на экран входа.

### Улучшения:
- Добавлен ENV switch в ApiConst для быстрого переключения между ngrok и prod одной строкой (_useNgrok).
