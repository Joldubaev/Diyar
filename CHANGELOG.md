## [3.5.9+91] - 2026-05-21

### Исправления:
- Исправлен механизм обновления токенов: refresh token теперь работает корректно для всех datasource-ов (ранее sl<Dio>() не имел обработки 401).
- Устранён дедлок при обновлении токена: запрос на /refresh-token теперь идёт через отдельный Dio без QueuedInterceptorsWrapper.
- Исправлено затирание номера телефона после рефреша (phone: '' → null).
- Устранён двойной рефреш при параллельных 401-ошибках.
- Исправлено сохранение нового refresh token после ротации (ранее сохранялся старый).
- При невалидном refresh token (401) приложение теперь автоматически разлогинивает пользователя и перенаправляет на экран входа.

### Улучшения:
- Добавлен ENV switch в ApiConst для быстрого переключения между ngrok и prod одной строкой (_useNgrok).

## [3.5.8+90] - 2026-05-15

### Исправления:
- Исправлена ошибка сброса темы и сохранённого адреса после перезапуска приложения — `logout()` больше не очищает все SharedPreferences, а удаляет только токены и данные пользователя.
- Исправлены цвета тёмной темы на странице «О нас», в карточках залов и в диалоге регистрации.
- Исправлена логика навигации в диалоге регистрации — больше не сбрасывается весь стек навигации.
- Исправлен баг с переполнением (BOTTOM OVERFLOWED) на странице поиска блюд.

### Улучшения:
- Расширена зона доставки на карте — теперь охватывает Кант и Новопокровку.
- Добавлен параллельный поиск адресов через suggest + searchByText по всей зоне обслуживания для более полных результатов.
- Улучшено качество фотографий блюд в сетке и на странице деталей (FilterQuality.high, увеличен кэш изображений, используются полные URL фото).
